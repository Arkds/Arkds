### Qué hago (en la práctica)
- **WordPress a medida**: páginas corporativas, landing pages, catálogos y **WooCommerce** con personalizaciones (plantillas, child themes, hooks, shortcodes, bloques, UI y funciones propias).
- **Custom WordPress**: formularios, endpoints, páginas privadas, paneles internos, shortcodes dinámicos, optimizaciones de rendimiento y mantenimiento.
- **CRM/SIG**: módulos de ventas, puntos, asistencia, reportes, cursos, certificados, administración de usuarios y roles.
- **Automatización de certificados (en producción)**:
  - Generación automática de **certificados PDF** a partir de registros del CRM (curso/usuario/fechas/estado).
  - Plantillas personalizadas (múltiples diseños) con posicionamiento dinámico de textos y control de estilos.
  - Normalización de nombres, saltos de línea, escalado de texto y ajuste de campos según longitud.
  - Integración con **API** para consulta de datos del estudiante/curso y emisión del certificado en tiempo real.
  - Generación de **códigos únicos** por certificado y reglas para evitar duplicados o inconsistencias.
  - Flujo de **re-emisión/duplicado** cuando aplica (correcciones, re-descarga, validación del registro).
  - **Verificación**: endpoints/página de verificación para confirmar autenticidad por código.
  - Integración de **QR** para verificación rápida y acceso directo a la ficha del certificado.
  - Registro de eventos básicos (emisión, re-emisión, descargas) para trazabilidad interna.
  - Manejo de errores y validaciones: datos incompletos, curso no disponible, bloqueos por estado, etc.
- **Integración de APIs (real y útil)**:
  - Consumo de APIs REST (GET/POST), autenticación por tokens/headers, paginación y filtros.
  - Webhooks para automatizaciones entre sistemas (notificaciones, sincronización, disparadores).
  - Integraciones típicas: validación/consulta de datos, endpoints internos, automatización de reportes y certificados.
  - Estrategias de robustez: timeouts, reintentos, logs, respuestas fallback y control de errores.
- **Analítica y medición**:
  - Implementación de **Google Analytics (GA4)** y **Google Tag Manager (GTM)**.
  - Configuración de eventos y conversiones básicas: clics a WhatsApp, envíos de formulario, CTA, compras/checkout (según sitio).
  - Etiquetado por campañas (UTM), medición simple de embudos y soporte para decisiones comerciales.
- **SEO técnico básico**:
  - Optimización on-page: titles, metas, headings, enlaces internos, estructura y indexación.
  - Performance: optimización de recursos, caché, compresión, lazy loading (según entorno), Core Web Vitals (básico).
  - Buenas prácticas: sitemap/robots, canonical, URLs limpias (cuando aplica).
- **Infraestructura, dominios y despliegue**:
  - Despliegue y administración de **VPS** (Linux) con **Apache/Nginx** y **HestiaCP**.
  - Manejo de **dominios y hosting** (incluye **cPanel** cuando aplica): estructura de sitios, rutas, permisos y operación.
  - Configuración **DNS**: registros A, CNAME, TXT, MX; manejo de **nameservers** y propagación.
  - SSL/TLS: configuración y renovación (por ejemplo, Let’s Encrypt según entorno).
  - **Cloudflare (básico/operativo)**: DNS, proxy, caché, reglas simples, optimización/seguridad básica (WAF/Firewall básico según necesidad).
- **Soporte operativo**:
  - Iteración rápida de features, corrección de bugs, mejoras UI/UX y acompañamiento a usuarios internos.
